# CLANOS foundations

Every colour, font, size, space and radius comes from `src/styles/tokens.css`, which the CLANOS
design package generates. Use the Tailwind utilities mapped from the tokens (`bg-s1`, `text-mut`,
`p-sp-16`, `rounded-lg`, `t-body`) or the variables themselves. Tailwind's own palette, type scale,
radii and numeric spacing are switched off, so a raw value simply doesn't exist.

The rules live in `AGENTS.md`; the design reference (screen inventory, previews and the Figma
link) lives in `_docs/design/`.

## Space, radius and layout

- Space: `sp-4` `sp-6` `sp-8` `sp-10` `sp-12` `sp-16` `sp-20` `sp-24` `sp-28` `sp-32`, e.g. `gap-sp-12`.
- Layout (switches at 768px): `gutter`, `section`, `list`, `card`, `control`, `control-sm`, `touch`,
  `top-bar`, `side-panel`, `bottom-bar`, e.g. `px-gutter`, `h-control`, `w-side-panel`.
- Radius: `rounded-xs` (badges), `-sm` (small buttons, chips), `-md` (buttons, inputs), `-lg`
  (cards), `-xl` (dialogs, sheets), `-full` (pills, avatars, toggles).
- A value that isn't a token? Use the closest token and add `TODO(token): <what's missing>`.
